# Research

This applies whenever the finding-out is done by someone other than the one deciding — a
sub-agent, a second session, another model. Two of these rules are about how the work travels
out, one about how its result comes back in.

- **Contradictory evidence arrives as a contradiction; the researcher does not reduce it to one
  answer.**
  Why: reconciling in the middle layer is exactly where a condition gets dropped.

- **The report is written as the work finishes, not at the end; a report that exists only in
  context does not exist. Interrupted work stays handoverable: what is done · what is left · the
  single next step · the sources scanned.**
  Why: a quota can run out at any moment.

- **A delivered report is checked against what was deleted first: the removed lines in the diff
  are read before the added ones.**
  Why: an agent told to "add" overwrites the end of a page while adding its section, and the
  loss is invisible in the added text.

These rules apply only where the runtime can dispatch work to other agents or sessions; where it
cannot, there is nothing here to apply.
