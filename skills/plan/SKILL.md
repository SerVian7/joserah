# Plan

This applies to whoever is carrying out a plan, not to whoever wrote it. A plan is an
instruction, and an instruction that no longer fits the work is a question, not a gap to fill.

- **When plan and reality disagree, stop and report it; do not improvise.**
  Why: a wrong line number in the plan turns into a silent error the moment the executor invents
  around it.

This rule applies only where the runtime can dispatch work to other agents or sessions; where it
cannot, there is nothing here to apply.
