# Dispatch

This applies at the moment work is placed — before it starts, not after it stalls. Placement is
capability against cost against what is left of each quota.

- **Effort level follows the tool's remaining quota, not the difficulty of the job; the tightest
  quota never gets the highest effort.**
  Why: high effort on a narrow quota cuts the work off in the middle.

- **A second local session on the same machine is a lane and goes on the table; "renting the same
  model twice" only counts when it means paying another provider.**
  Why: a second local session is not an extra cost.

These rules apply only where the runtime can dispatch work to other agents or sessions; where it
cannot, there is nothing here to apply.
