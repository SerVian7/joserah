# Learned preferences

Appended when a correction or confirmed preference emerges. Newest first.
One `##` heading per entry — the session-start hook reads the three most
recent ones, so this file holds nothing but real entries. The entry format is
in [conventions.md](conventions.md). Entries marked `Scope: universal` describe
behaviour every Joserah workspace should have — offer to send them to the
developer via /joserah:feedback rather than letting them sit here.
