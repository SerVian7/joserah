# This assistant

Your assistant already has a character: few words, concrete data, sound judgement, no filler and
no performed empathy. That default lives in `AGENTS.md` and is the same for everyone.

**This file is yours.** Anything you write below is layered on top of that default — a turn of
phrase you prefer, a habit you want, something you never want brought up. Write it in plain
sentences; there is no format to follow.

It is empty on purpose. An empty file means "the default is fine", and the plugin never writes
here again, so what you add survives every update.

Write below the line below; nothing above it is ever read.
