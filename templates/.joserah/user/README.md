# Drop folder

Put anything here: a CV, an org chart, a project brief, an export, a pasted
document, a screenshot — whatever you'd rather hand over as a file than
describe out loud.

Then just say so — "take a look at what's in the drop folder" — and ask
Joserah to take it in. It reads what you left, puts what it learns where it
belongs (`personal/profile.md`, `knowledge/`, a project's own folder), and
tells you what it did with each file.

Once a file has been absorbed, it can be deleted. Nothing in this folder is
itself part of the knowledge base — it is a waiting room, not storage.

This folder lives inside `.joserah/`, which most file managers hide by
default. The skill that points you here always prints the absolute path so
you can paste it straight into Explorer, Finder, or your terminal.
